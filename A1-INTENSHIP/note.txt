1.)Don't get too comfortable with created_at__date

For serious high-volume systems, we'll learn why date extraction can interfere with efficient index usage depending on the database/query plan.

A production-oriented approach is often a range:

start_of_day
        ↓
created_at >= start
        AND
created_at < end

We'll implement that properly when we build the dashboard selector.
